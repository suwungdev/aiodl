AIODL API Docs

API sederhana untuk memproses URL media dari berbagai platform yang didukung AIODL. Cocok untuk website, bot, automation, dan aplikasi sendiri.

IntroductionEndpointRequestResponseSupported URLsErrorsExamples

Introduction

AIODL menyediakan endpoint HTTP yang menerima URL publik dan mengembalikan informasi media yang berhasil ditemukan.

Public API: endpoint downloader dapat dipanggil tanpa API key. Gunakan secara wajar dan hormati rate limit.

API Endpoint

POSThttps://aiodl.suwung.id/api/scrape

Gunakan Content-Type: application/json.

Request

Body request membutuhkan property url.

JSON
{
  "url": "https://www.tiktok.com/..."
}

Response

Contoh response ketika media berhasil ditemukan:

JSON
{
  "status": true,
  "platform": {"id": "tiktok", "name": "TikTok"},
  "result": {
    "title": "Example",
    "thumbnail": "https://...",
    "downloads": [
      {"id": 1, "type": "VIDEO", "quality": "HD", "url": "https://..."}
    ]
  }
}

Error Codes

StatusArtiKeterangan
200SuccessMedia berhasil ditemukan.
400Bad RequestURL tidak valid atau tidak didukung.
429Rate LimitedTerlalu banyak request.
502Scraper ErrorMedia gagal diproses.
503MaintenancePlatform sedang dinonaktifkan.

Usage Examples

JavaScript

JAVASCRIPT
const res = await fetch(
  "https://aiodl.suwung.id/api/scrape",
  {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({url: "https://www.tiktok.com/..."})
  }
);
console.log(await res.json());
